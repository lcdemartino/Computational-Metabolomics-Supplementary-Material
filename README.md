# AI-for-Metabolomics-Supplementary-Material
Supplementary material associated with the PhD thesis "AI for Metabolomics: Strategies for enhancing data analysis and metabolite annotation".

**AI for Metabolomics: Strategies for enhancing data analysis and metabolite annotation**  
Luca De Martino  
Italian National Ph.D. in Artificial Intelligence – Health and Life Sciences  
Università Campus Bio-Medico di Roma / CNR-IBIOM  
May 2026

## Repository content

### Supplementary Table S1
Complete metabolomics dataset used for downstream analyses, including LC–MS features, metabolite annotations, and associated quantitative/statistical information.

### Supplementary Table S2
Processed transcriptomic dataset derived from Epstein et al. and used for downstream integration analyses. The table includes gene identifiers, gene names, original log10 expression ratios for the rho-plus/rho-zero comparison, and the corresponding log2 fold-change values.
